## 목표와 수행 내용

사용자가 스태미나 0 상태에서는 대시 불가임을 확인했다. 명세와 관찰 가능한 로컬 확인 항목에 반영했다.

## 어려움과 해결 시도

새 장애 없음. 소모량 미만의 양수 잔량과 0 상태를 구분했다.

## 검증

수정한 0 상태 규칙을 문구 검색으로 직접 확인한다. 기능 구현·런타임·서버 검증은 미실행이다. 전체 Git/LFS 상태는 미검증이다.

## 결정과 학습

잔량이 양수이면 소모량 미만이어도 대시 가능하고, 0이면 대시 불가다. 소진 후 회복 지연·회복 속도·소모량 수치는 미정이다.

## 인수인계

PM에 누적 스태미나 결정을 보고한다. 다음 협의는 공중 대시 횟수와 카메라 등 남은 기본 동작이다. 구현·커밋·push·PR·병합은 하지 않는다.
