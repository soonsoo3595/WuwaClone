## 목표와 수행 내용

사용자의 추가 설명으로 지상·공중 대시 방향을 갱신했다. 이동 입력 시 캐릭터 이동·시선 방향으로 전방 대시, 무입력 시 후방 대시다. 대각선 이동도 해당 방향으로 대시한다. 공중 대시는 같은 방향으로 한 번 더 점프하는 동작으로 기록했다. 캐릭터별 공중 체공 이동은 별도 변형 후보로 남겼다.

## 어려움과 해결 시도

'착지할 때까지만 점프 사용가능'은 횟수 제한을 명확히 나타내지 않아 착지 전 1회로 추정하지 않았다. 기본 캐릭터의 공중 대시 횟수와 착지 시 초기화 여부를 짧게 확인한다.

## 검증

문서 수정 후 rg로 대시·착지 관련 항목을 읽어 확인했다. 최초 정규식 조회는 지원하지 않는 유니코드 속성 이름으로 실패해 단순 문구 검색으로 수정했다. 구현·런타임·네트워크 검증은 미실행이며 Git 전체 상태와 바이너리 변경 여부는 미검증이다.

## 결정과 학습

대시 방향은 지상·공중에서 동일한 입력 유무 규칙이다. 거리·높이·횟수·스태미나 수치·회복은 미정이다. 캐릭터별 변형 가능성이 기본 요구사항 구현을 의미하지는 않는다.

## 인수인계

공중 대시 사용 횟수를 확인한 뒤 스태미나 규칙 협의를 진행한다. 구현 배정·커밋·push·PR·병합은 하지 않는다.
