## 목표와 수행 내용

사용자가 설명한 명조 이동 동작을 참고로 기록하고, 대시·스태미나도 포함해야 한다는 명시적 요청을 첫 마일스톤 범위에 반영했다. 이전 Shift 달리기·스태미나 제외 추천안을 교체했다. 로컬과 서버 검증 후보에 대시 및 스태미나 항목을 추가했다. 구현·GitHub 변경은 하지 않았다.

## 어려움과 해결 시도

질문 입력 도구가 사용자에게 보이지 않아 본문으로 질문을 다시 제시했다. 사용자는 추천안을 일괄 수락하지 않고 참고 게임의 동작을 설명했다. 참고 설명 전체를 확정 명세로 해석하지 않고 명시적으로 요청한 대시·스태미나 포함과 세부 미정 사항을 구분했다.

## 검증

기존 명세와 로그를 Get-Content로 읽고 초안을 수정했다. 수정 문서의 직접 읽기와 docs 범위 상태 조회 결과를 확인한다. UE 빌드·로컬 실행·서버·Android QA는 미실행이다. 전체 Git/LFS와 바이너리 변경 여부는 미검증이다.

## 결정과 학습

대시·스태미나 포함은 확정했다. Ctrl 토글·Shift 대시 및 비소모 걷기·달리기는 사용자 참고에 맞춘 안이다. 대시 방향, 공중 대시 효과·횟수, 스태미나 부족·회복 규칙을 추가 확인한다. 활공·벽 타기·수영·회피 판정·투명화는 포함 여부 미정이며 공격·전투 구현 제외를 유지한다.

## 인수인계

PM에 사용자 범위 확대와 미정 항목을 보고한다. 사용자와 세부 조작 규칙 협의를 계속한다. 커밋·push·PR·병합은 요청하지 않는다.
