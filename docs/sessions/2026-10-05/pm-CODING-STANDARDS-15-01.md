# PM — CODING-STANDARDS-15 / 01

- 날짜: 2026-10-05 (Asia/Seoul)
- 브랜치: codex/15-coding-standards
- 관련 Issue: https://github.com/soonsoo3595/WuwaClone/issues/15

## 목표와 수행 내용

사용자 요청에 따라 코드 개발 전 코딩 규약 논의 이슈와 작업 브랜치를 생성했다. 최신 origin/dev에서 분기하고 원본 로컬 체크아웃을 해당 브랜치로 전환한 뒤 원격에 등록했다. 언리얼 개발 세션에 규약 초안 제안을, 코드 리뷰 세션에 규약 논의를 요청한다.

## 어려움과 해결 시도

QA/코드 리뷰는 요청 기반으로 운영하며 이번 코드 리뷰 세션 전달은 사용자의 명시적 요청에 따른 것이다. 규약 작성과 게임 코드 구현을 구분한다.

## 검증

브랜치 생성 전 로컬 변경 없음, 생성 및 push 성공, 로컬 체크아웃 codex/15-coding-standards 확인. 게임 코드 구현과 QA는 수행하지 않았다.

## 결정과 학습

언리얼 개발 세션이 초안 작성 담당이며 코드 리뷰 세션은 같은 문서를 동시에 수정하지 않는다. 최종 규약은 사용자가 결정한다.

## 인수인계

규약 문서 후보는 docs/project/coding-standards.md다. 필수·권장·미정 규칙을 구분하고 초안 작성 후 리뷰를 진행한다. 코드 구현 및 규약의 일괄 적용은 별도 요청을 기다린다.
