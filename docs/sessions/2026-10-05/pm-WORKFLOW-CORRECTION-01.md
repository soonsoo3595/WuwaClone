## 목표와 수행 내용

사용자 지시에 따라 QA/코드 리뷰 자동 요청을 중단하고 작업 브랜치로 로컬 체크아웃을 전환한 뒤 작업하도록 운영 규칙을 정정했다. 코드 리뷰 세션에 진행 중 검토 중단을 전달했다.

## 어려움과 해결 시도

MCP uproject 변경은 이미 작업 브랜치에 커밋돼 있었으나 원본 dev에도 미커밋 수정본이 남아 있었다. 같은 HEAD로 작업 worktree를 detached로 전환한 후 원본 브랜치 전환을 시도했지만 Git이 로컬 수정으로 차단했다. Git 정규화 blob이 작업 브랜치 blob과 동일한 것을 검증하고 해당 파일만 인덱스에 맞춘 뒤 원본 체크아웃을 codex/unreal-mcp-setup으로 전환했다. dev에 추가 커밋하지 않았다.

## 검증

전환 전후 uproject 실제 파일 SHA256 동일, 작업 브랜치에서 해당 파일 수정 표시 없음. QA/코드 리뷰 및 게임 테스트는 수행하지 않았다. 문서 변경은 공백 검사만 수행한다.

## 결정과 학습

작업 브랜치 커밋 여부와 원본 로컬 체크아웃 상태를 함께 확인한다. QA/코드 리뷰는 사용자의 명시적 요청이 있을 때만 진행한다.

## 인수인계

운영 규칙 변경을 PR #14에 함께 반영한다. 최종 병합은 사용자 결정이다.
