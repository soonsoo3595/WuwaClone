## 목표와 수행 내용

기존 feat/TRIPO-SETUP-plugin의 3b906dd 및 b9b87c0은 원격에 올리지 않고 로컬에 보존한다. 새 브랜치는 최신 dev에서 직접 분기해 기존 플러그인 파일이 공개 이력에 들어가지 않도록 했다. 공개 대상은 제외 규칙·선택적 Editor 플러그인 설정·별도 설치 문서·이 로그다.

main에는 플러그인 경로 제외 규칙을 추가해 미추적 배포본을 로컬 설치로 정리했다. 모델·플러그인 설치·Config 변경을 삭제하거나 되돌리지 않았다. main의 .gitignore 변경은 로컬 미커밋 상태이며 PR 통합과 구분한다.

## 어려움과 해결 시도

패키지 내 LICENSE/COPYING/README 및 공식 DCC Bridge 설치 안내에서 해당 배포본의 공개 재배포 허용 근거를 확인하지 못했다. 이를 재배포 금지 확정으로 해석하지 않고 배포본 업로드를 보류했다. 플러그인 없는 체크아웃을 고려해 Optional 설정을 사용했으며 실제 UE 동작 검증은 별도다.

## 검증

제외 규칙, JSON 설정, 변경 경로, 공개 후보의 시크릿 패턴 및 diff --check를 확인한다. 기존 LFS 설정은 변경하지 않으며 공개용 작업 공간은 LFS smudge를 생략해 생성했다. UE 빌드·실행·모델 전송 검증은 미수행이다. 로컬 Config의 토큰 값은 출력하거나 커밋하지 않는다.

## 결정과 학습

배포본이 든 로컬 브랜치에 삭제 커밋을 추가해 push하면 과거 이력도 공개되므로 dev에서 새 공개용 브랜치를 분기했다. 최종 병합은 사용자 결정이다.

## 인수인계

PR과 검증 결과를 요청 채팅 및 PM에게 전달한다. 공통 상태 문서 갱신은 PM이 조율한다. main의 로컬 Config 변경은 별도 검토가 필요하며 이 PR에는 포함하지 않는다.
