# WuwaClone

언리얼 게임 서버 직군 포트폴리오를 위한 개인 학습 프로젝트입니다. Wuthering Waves의 캐릭터 중심 3인칭 액션을 참고하며, 공식 프로젝트와 관련이 없습니다.

## 목표와 상태

- 개발 과정부터 공개하는 단독 개발 프로젝트입니다.
- UE 5.8.2 소스 빌드와 C++을 사용합니다.
- 첫 목표는 캐릭터의 걷기·달리기·점프·카메라 조작 구현 후 데디케이티드 서버에서 이동 동기화를 검증하는 것입니다.
- Windows PC와 Android(Galaxy Z Flip5)를 대상으로 합니다.
- 이후 C# 백엔드, 외부 로그인, MySQL·Redis, Docker 운영, 런처·패치·배포를 구현할 예정입니다.
- 현재 게임은 생성된 언리얼 템플릿 단계이며, 위 기능의 완성을 의미하지 않습니다.

## 개발 환경

Git LFS를 설치하고 저장소를 가져온 뒤 `git lfs pull`을 실행합니다. 로컬 소스 빌드 엔진과 `WuwaClone.uproject`를 연결하고 프로젝트 파일을 생성합니다. 엔진 소스 자체는 이 저장소에 포함하지 않습니다. 정확한 엔진 커밋과 재현 가능한 빌드·실행 절차는 확인 후 문서화할 예정입니다.
